What it does — and who it is for

PrivateRedact redacts personally identifiable information from documents automatically. Regex rules catch structured PII: SSNs, card numbers, IBANs, dates of birth. A local LLM catches the semantic PII that regex misses: names, addresses, diagnoses, codenames. It redacts only the value — 555-1234, not the label Phone:, and never the whole line.

Exports are real. PDF pages are rasterized and rebuilt, so there is no recoverable text layer underneath the black boxes. DOCX redaction edits the file in place and keeps Word formatting. A post-export leak scan re-OCRs the output and tells you exactly what survived.

Built for people who handle other people's data:

  • Law firms and paralegals preparing discovery or FOIA releases
  • Healthcare and HR staff working under HIPAA / GDPR constraints
  • Researchers sharing documents with PII scrubbed before publication
  • Consultants and agencies that cannot put client files in a cloud tool
  • Anyone redacting PII from a PDF before sending it to an LLM or a third party

Compliance presets are included: HIPAA, PCI DSS, GDPR, HR, Employment, Legal, Financial, Vendor, and Names-Only.

Why 100% offline matters

Cloud redaction defeats itself

Most "secure redaction" tools are web apps. To redact a private document, you first upload the exact document you are trying to protect — to a server you do not control, under policies you cannot audit. For law firms, clinics, HR departments, and agencies, that alone can violate a confidentiality obligation.

Naive desktop tools fail the other way

Many free PDF tools black out the rendering, not the text. The characters underneath the black rectangle stay selectable, copyable, and removable. That is how "redacted" government PDFs leak. PrivateRedact rebuilds the page as an image-level export, so there is nothing underneath to recover.

The LLM is local, not a cloud API

PrivateRedact uses a local model (via Ollama, offered as a click-gated one-click install on first run) for semantic PII detection. You get LLM-grade recall for names, diagnoses, and addresses — with the network cable effectively unplugged. Regex-only mode also works without any model.

Trust is verified, not promised

After export, the app re-OCRs the output file and reports exactly what (if anything) survived. It never claims "clean" on a failed scan. Metadata — PDF Info/XMP, DOCX properties, image EXIF — is stripped by default.

Frequently asked questions

How do I redact a PDF without Adobe Pro?
Load the PDF into PrivateRedact, let the hybrid engine mark PII, review the proposed redactions, and export. You get a rasterized PDF with the sensitive values permanently removed — no Adobe subscription needed. This is the main reason most buyers choose it over Acrobat's redaction workflow.
Is my document uploaded anywhere?
No. PrivateRedact is 100% offline. Detection, OCR, the local LLM, and export all run on your machine. There is no account and no upload step. You can verify with your firewall or by going offline entirely — the app still works.
Can a redacted PDF made with PrivateRedact be un-redacted?
No. Export rasterizes each page and rebuilds the PDF, so the text layer underneath the black boxes no longer exists. There is nothing to select, copy, or peel back. The post-export leak scan re-checks the file and reports anything that survived.
What makes it different from other PII redaction software?
Three things. First, detection runs fully offline — a local LLM, not a cloud API, so the document never leaves your machine. Second, it redacts value-only spans instead of whole lines, so the document stays readable. Third, every export is verified with an automatic leak scan instead of a "trust me" claim.
Does it work on scanned documents and images?
Yes. Scanned and image-based PDFs go through built-in OCR (Tesseract), with an optional vision-model double-check on low-quality scans. JPG/PNG images, DOCX, and plain text files are also supported.
Which PII types does it catch?
Structured formats by regex: SSNs, payment card numbers, IBANs, dates of birth. Semantic PII by local LLM: names, addresses, diagnoses, codenames, and similar context-dependent identifiers. Compliance presets (HIPAA, PCI DSS, GDPR, HR, Legal, Financial, Vendor, Names-Only) tune the detection scope per use case.
What platforms are supported?
macOS on Apple Silicon (signed and notarized) and Windows x64. You need about 8 GB RAM; the app selects the model size automatically. Intel Mac and Linux builds are planned.
