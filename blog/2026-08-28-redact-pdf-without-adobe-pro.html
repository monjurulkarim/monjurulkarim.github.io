How to Redact a PDF Without Adobe Pro

You need to redact a PDF, and you don't own Adobe Acrobat Pro. So: how to redact a PDF without Adobe Pro? You have four real options: macOS Preview markup, free online tools, paid desktop software, and offline tools with built-in PII detection. Each works. Each fails in a specific way. This post shows where the failure lines are, so you can pick based on how sensitive the document is.

I build document-privacy tooling (PrivateRedact), so I'll be blunt about what my own tool does and doesn't fix. But first, the free options — because for many jobs, they're fine.

Why most redaction fails silently

Redaction is not drawing a black box. A PDF stores text as a text layer under the visual page. Cover the text with a black rectangle and the words are still in the file. Anyone can select-all, copy, and paste your “redacted” text into a new document.

# On a badly "redacted" PDF, the secret never left the file:
pdftotext redacted.pdf - | grep -i ssn
# 512-55-9821

This is the most common redaction failure. It has shipped in court filings, government releases, and at least one well-known congressional report. Adobe's own documentation is explicit: proper redaction removes the content, then you apply the mark. Their redaction guide covers it — but it requires Acrobat Pro.

So the question “how do I do this without Adobe Pro” becomes: which tool actually removes content, and which just paints over it?

Option 1: macOS Preview markup — free, on every Mac

Preview's markup tool draws opaque shapes over text. For a PDF exported as an image (a flat raster), this is a genuine redaction — there is no text layer under the box, so nothing can be extracted.

For a normal text PDF, it is not a redaction. It's a cover-up:

  1. Open the PDF in Preview.
  2. Show the Markup toolbar (Shift+Cmd+A).
  3. Draw a filled rectangle over each sensitive item.

The limitation: on many PDFs, the black box is an annotation or overlay object. The text underneath is untouched. Someone can open the file in Acrobat or a PDF editor, delete the rectangle, and read the original text. This has leaked real documents more than once. If you use Preview markup on a text PDF, the safe move is to print to PDF first (File → Print → PDF → Save as PDF), which flattens the page to an image, then mark up that flattened copy.

Preview also has no search-based redaction. You find every name, phone number, and account number by eye. On a 40-page document, you will miss one.

Option 2: Free online redaction tools (free, but read this)

Sites like Smallpdf, iLovePDF, Sejda, and PDFescape let you drag a PDF into a browser and black out regions. The tools are convenient and mostly do remove text properly.

The problem is upstream of the redaction: you upload the document to someone else's server. If the PDF contains patient data, client records, or HR files, you have just transmitted it to a third party to avoid buying a $20 tool. For regulated data (HIPAA, GDPR, client confidentiality), that upload can itself be the disclosure event. “We deleted it after processing” is a promise, not a control.

My rule: online tools are fine for documents you'd also be comfortable emailing to a stranger. If you wouldn't, don't upload it.

Option 3: Paid desktop tools (Adobe Pro alternatives)

If you redact daily and need bates numbering, court-compliant workflows, or team licensing: dedicated products like CaseGuard, Redactable, or PDF Redactor do the job. Adobe's own comparison shows what Pro-tier redaction includes. Expect $10–50/month per seat. Good tools, real cost — priced for teams that redact all day, not for a researcher sending a report twice a month.

FAQ

Can I redact a PDF without Adobe Acrobat Pro?

Yes. Preview markup works on flattened/image PDFs, online tools handle non-sensitive documents, and offline desktop tools like PrivateRedact redact sensitive files without any upload.

Does blacking out text in Preview actually redact it?

Only if the PDF has no extractable text under the box — i.e., it's already an image. On a text PDF, the markup is an overlay and the text underneath can be recovered. Flatten first (print to PDF), then mark up.

How do I redact a PDF for free without uploading it?

Use an offline tool. PrivateRedact runs entirely on your machine and offers a free trial. Preview markup on a flattened copy also works for small jobs.

What PII do regex-based redaction tools miss?

Names, physical addresses, and diagnoses — anything without a fixed format. That's why PrivateRedact adds a local LLM pass on top of regex: patterns catch SSNs and card numbers, the LLM catches the rest.

Can a redacted PDF be un-redacted?

If the redaction was a drawn box or annotation over live text: yes, trivially. If the pages were rasterized on export — as PrivateRedact does — there is no text left to recover.
