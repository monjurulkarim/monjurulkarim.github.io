Rename Multiple Files on Mac: 4 Ways That Work (2026)

A phone dump lands in your Downloads folder — IMG_4021.png through IMG_4189.png — or a folder full of scan001.pdf, scan002.pdf that means nothing six months later. Renaming them one at a time is not a solution. There are four ways to rename multiple files mac users actually have, and they solve different problems: Finder’s built-in batch rename for text patterns, a Terminal loop for scripted control, an on-device AI renamer that reads what each file is, and a hybrid: sort first, then rename. They differ on effort, precision, and what the final names can say.

The short answer

  • Same fix everywhere — “scan” → “invoice-2026”: Finder’s built-in multi-rename. Select, Control-click, Rename. No installs.
  • Prefix/suffix or numbering, on your own terms: a Terminal loop. Total control, needs a dry run first.
  • Files you can’t identify by name — camera dumps, receipts, scans: an on-device AI renamer that reads the contents and writes dates-first names (that’s the one I built — disclosure below).
  • A whole messy folder, not just names: reorganize first, rename second. Rename is the last step of a cleanup, not the first.

Method 1: Finder’s built-in batch rename

Finder has shipped a multi-item renamer for years and it’s the right first tool. Per Apple’s guide: select the items, Control-click one of them, and choose Rename. In the “Rename Finder Items” pop-up you get three modes:

  • Replace text — enter the text to remove in Find, and the replacement in “Replace with”. This is the move for scan001.pdf → invoice-scan001.pdf style fixes.
  • Add text — put text before or after the current name, keeping what’s already there.
  • Format — pick a name format and choose whether the index, counter, or date goes before or after the name; enter the name in “Custom Format” and the starting number. This turns a selection into trip-001.jpg, trip-002.jpg, and so on.

Two of Apple’s own warnings are worth repeating because they’re the two classic mistakes: don’t change filename extensions (a renamed extension can stop the file opening), and don’t rename app folders or system items like the Library folder.

What Finder can’t do: every mode works on the characters in the existing name. It never looks inside the file. IMG_4021.png contains no information about what the photo shows, so no Find/Replace or numbering scheme can make that name readable.

Method 2: A Terminal loop — full control, run dry first

If you’re comfortable in Terminal, a small loop renames any set of files with exact control over the pattern. Preview before touching anything:

cd ~/Downloads/photos
for f in *.png; do printf '%s -> trip-%s\n' "$f" "$f"; done

Nothing is renamed yet — that just prints the mapping. When the plan looks right:

cd ~/Downloads/photos
i=1
for f in *.png; do
  mv "$f" "$(printf 'trip-%03d.png' "$i")"
  i=$((i+1))
done

You get trip-001.png, trip-002.png… in loop order, with zero new software. The same loop handles prefixes and suffixes by editing the mv target. The honest limits: it’s mechanical — names come from the old name and a counter, not from the file’s contents; and a bad pattern applies to every match at once, which is exactly why the dry run comes first. FAQ

Does Finder batch rename work on any Mac?

Yes — the multi-item renamer (select → Control-click → Rename) is built into Finder on every current macOS. Apple’s guide documents the Replace text / Add text / Format modes.

Is it safe to rename files in bulk?

Keep the extension unchanged, skip app and system folders, and prefer tools that show you the result before applying. Finder shows the change per mode; a Terminal loop should print its mapping first; TidyMind asks you to approve the plan and can undo any session.

Can I number files when renaming in bulk?

Yes. Finder’s Format mode adds an index or counter with a starting number; in Terminal, a counter variable in the loop does the same.

Why not just rename files one at a time?

You can — but for a hundred photos or scans the name was never the problem, the volume is. Batch methods make the pattern change once instead of a hundred times.
